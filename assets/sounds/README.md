# Sound Effects for ConfessBox

This folder contains sound effects for user interactions. Download the following 1-second sound effects:

## Required Sound Files

1. **like.mp3** - For reaction/like interactions
   - Suggested: Uplifting "pop" or "ding" sound
   - Duration: ~0.5-1s
   - Download from: https://pixabay.com/sound-effects/search/pop/ or https://freesound.org/

2. **comment.mp3** - For comment submissions
   - Suggested: Soft "whoosh" or "send" sound
   - Duration: ~0.5-1s
   - Download from: https://pixabay.com/sound-effects/search/whoosh/

3. **post.mp3** - For posting confessions
   - Suggested: Success "chime" or celebratory sound
   - Duration: ~1s
   - Download from: https://pixabay.com/sound-effects/search/success/

4. **notification.mp3** - For notifications
   - Suggested: Attention-grabbing "bell" or "notification" sound
   - Duration: ~0.5-1s
   - Download from: https://pixabay.com/sound-effects/search/notification/

## Quick Download Links

**Free Sound Resources:**
- Pixabay: https://pixabay.com/sound-effects/
- Freesound: https://freesound.org/
- Zapsplat: https://www.zapsplat.com/

## Format Requirements
- Format: MP3
- Duration: 0.5-1 second
- Volume: Normalized (not too loud)
- Sample Rate: 44.1kHz recommended

## Installation
1. Download the 4 sound files
2. Rename them to: `like.mp3`, `comment.mp3`, `post.mp3`, `notification.mp3`
3. Place them in this folder (`assets/sounds/`)
4. Restart the Expo app

**Note:** The app will work without sound files (haptics only) but sounds enhance the UX significantly.
