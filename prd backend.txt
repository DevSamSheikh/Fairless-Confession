# ConfessBox Backend Development PRD

## 1\. Overview

**App/Website Name:** ConfessBox

ConfessBox is an anonymous text-based confession platform designed as a Progressive Web App (PWA) that allows users to share their thoughts and experiences while maintaining anonymity from other users. The platform features a dual-posting system where users can share confessions publicly or within specific societies (similar to private groups). While users appear anonymous to each other with generic display names, comprehensive tracking and monitoring capabilities are available exclusively to administrators for security and moderation purposes.

The target audience includes individuals seeking a safe, anonymous space to share personal experiences, thoughts, and confessions. The app addresses the need for anonymous self-expression while maintaining accountability through administrative oversight, creating a balance between privacy and security.

## 3\. Tech Stack

**Front-End:** React, Tailwind CSS & Vite (Already completed)
**Back-End:** Supabase

* Authentication: Supabase Auth with custom user tracking
* Database: Supabase (PostgreSQL) for user data, posts, societies, interactions
* Storage: Supabase Storage for any media assets
* Real-time: Supabase Realtime for live interactions
* Edge Functions: For complex business logic and tracking

**APIs & Integrations:**

* Email validation service API
* Geolocation API for IP tracking
* Device fingerprinting for MAC address capture
* SMS verification service for mobile number validation

**Security Features:**

* Row Level Security (RLS) policies
* JWT token authentication
* API rate limiting
* Data encryption at rest and in transit

## 7\. User Flow

### Registration and Onboarding Flow:

1. User opens ConfessBox PWA
2. Presented with login screen, selects "Register"
3. Completes registration form with full name, email, password
4. Accepts rules and privacy policy
5. System captures background details (timestamp, IP, MAC, mobile number)
6. Generates unique user ID with 2004 prefix
7. Email verification sent and confirmed
8. User directed to home feed tutorial

### Daily Usage Flow:

1. User opens app and logs in
2. System updates login tracking data
3. User browses home feed of public confessions
4. User can like, comment, or save interesting confessions
5. User navigates to societies tab
6. Joins new societies or browses joined society confessions
7. User creates new confession (public or society-specific)
8. System captures all posting metadata and tracking information
9. User interacts with other confessions through likes and comments
10. User checks their profile for confession statistics
11. User logs out when finished

### Confession Creation Flow:

1. User taps floating post button
2. Selects confession type (public or society)
3. If society selected, chooses specific society from joined list
4. Writes confession title and content
5. Selects appropriate category
6. Reviews confession before posting
7. Submits confession with full tracking capture
8. Confession appears in appropriate feed
9. User receives engagement notifications

### Society Interaction Flow:

1. User discovers new society through explore tab
2. Views society information and recent confessions
3. Joins society to access full content
4. Posts society-specific confessions
5. Interacts with other society members anonymously
6. Can leave society or manage created societies
7. All interactions tracked for administrative oversight
